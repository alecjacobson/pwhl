When you Google search "nhl" or "nba" you get a thing above the search results
that shows the past, current and upcoming games (with times and scores), a tab
for "standings" and a tab for "players".

Try it:

https://www.google.com/search?q=nhl
https://www.google.com/search?q=nba

There doesn't exist one for PWHL. So this is a chrome extension to create that
when the user searches pwhl

https://www.google.com/search?q=pwhl
https://www.google.com/search?q=PWHL
